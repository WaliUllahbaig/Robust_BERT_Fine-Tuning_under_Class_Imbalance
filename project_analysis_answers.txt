A2. Code Snippet (10–20 lines) — Custom Weighted Loss Trainer
──────────────────────────────────────────────────────────────
File: models/trainer.py, Lines 34–65

class WeightedLossTrainer(Trainer):
    def __init__(self, *args, class_weights=None, **kwargs):
        super().__init__(*args, **kwargs)
        self.class_weights = class_weights

    def compute_loss(self, model, inputs, return_outputs=False, **kwargs):
        labels = inputs.pop("labels")
        outputs = model(**inputs)
        logits = outputs.logits

        if self.class_weights is not None:
            weight = self.class_weights.to(logits.device)
            loss_fn = nn.CrossEntropyLoss(weight=weight)
        else:
            loss_fn = nn.CrossEntropyLoss()

        loss = loss_fn(logits, labels)
        return (loss, outputs) if return_outputs else loss

- Which lines are mine? Why written that way? (≤60 words):
  All lines are mine. The compute_loss override injects inverse-frequency class weights into CrossEntropyLoss to up-weight minority classes (surprise, love) during backpropagation. Weights are lazily moved to model device to support multi-GPU. Labels are popped from inputs so the base model doesn't receive them, avoiding double loss computation.

C. MODELING DECISIONS
================================================================================

C1. Task & Model Choice (≤100 words)
──────────────────────────────────────
Task type: Multi-class text classification (6 emotion categories).
Model family: BERT-base-uncased (110M parameters, 12 layers, 768 hidden dim).
Why over alternatives:
  - Over LSTM/BiLSTM: BERT's bidirectional self-attention captures long-range dependencies and contextual semantics far better than recurrent models for short text.
  - Over DistilBERT: BERT-base provides higher capacity for fine-grained emotion distinctions (6 classes with subtle boundaries like love vs. joy); DistilBERT sacrifices ~3% accuracy.
Most impactful hyperparameter tuned: learning_rate = 2e-5 (search range: 1e-5 to 5e-5). Larger LR caused training instability; smaller LR underfit within 5 epochs.

C2. Supervision Signal (≤60 words)
───────────────────────────────────
Supervised learning. Labels are human-annotated discrete emotion categories (0–5 mapping to sadness, joy, love, anger, fear, surprise). The dataset provides ground-truth class labels for every sample. Pre-training used masked language modeling (self-supervised pretext task by original BERT authors); our fine-tuning is fully supervised with the provided emotion labels.

D. EVALUATION & ERROR ANALYSIS
================================================================================

D1. Primary Metric & Trade-Off (≤60 words)
────────────────────────────────────────────
Primary metric optimized: Macro-F1 (0.8904 on test set). Trade-off: Macro-F1 weights all classes equally, which improves minority class performance (surprise F1=0.773) at the cost of slightly lower majority class performance. Using accuracy alone (0.93) would mask poor minority class recall and favor the dominant classes (sadness, joy).

D2. Concrete Failure Mode — Error Analysis (≤100 words)
────────────────────────────────────────────────────────
Failure mode found via per-class metrics:
  - "surprise" class: Precision = 0.690, Recall = 0.879, F1 = 0.773
  - The model over-predicts "surprise," causing many false positives (precision only 69%).
  - Confusion matrix analysis: "surprise" is most confused with "joy" and "fear."

Why it fails: "surprise" is the smallest class (572 train samples vs. 5,362 for sadness/joy — 9:1 ratio). Despite inverse-frequency weighting (w_surprise=4.66), the class lacks sufficient diversity for the model to learn robust decision boundaries. Lexical overlap between surprise and joy expressions (e.g., "wow", "amazing") further degrades precision.

Fix attempted: Applied inverse-frequency weighted CrossEntropyLoss (w_c = N / (K × n_c)), which improved surprise recall from ~0.60 (unweighted baseline) to 0.879, but at the cost of precision. Further mitigation would require data augmentation or oversampling.

D3. Final Validation Log & Overfitting (≤60 words)
────────────────────────────────────────────────────
Final validation log (epoch 5, step 10000):

Additional bias: dataset consists of English tweets only, limiting generalization to other languages/domains.

I1. Loss Function (≤60 words)
──────────────────────────────
Exact loss function minimized (weighted cross-entropy):

  L = - (1/N) * Σ_{i=1}^{N} w_{y_i} * log( exp(z_{i,y_i}) / Σ_{c=1}^{K} exp(z_{i,c}) )

where:
  - z_{i,c} = logit for sample i, class c
  - y_i = true class label for sample i
  - w_c = N / (K × n_c) (inverse-frequency weight for class c)
  - K = 6 (number of classes), N = 16,000 (training samples)

Regularization term: L2 weight decay = 0.01 (applied via AdamW optimizer to all parameters except bias and LayerNorm weights).

I2. Early Stopping (≤40 words)
───────────────────────────────
Early stopping with patience = 3 epochs. Selection criterion: eval_macro_f1 (greater_is_better=True). Best checkpoint selected at epoch 3 (step 6000) with eval_macro_f1 = 0.9144. Training continued to epoch 5 (early stopping counter reached 2 out of 3).
